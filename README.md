# AldarwishDev.github.io

Wasl prayer-times frontend: `/wasl/prayer-times/`. It fetches results from `https://api.ahmadaldarwish.com`; no calculation rules or regional datasets are shipped to browsers. The API runs privately on the owner’s PC through Cloudflare Tunnel and requires the PC to be online. City data attribution: GeoNames, CC BY 4.0.
